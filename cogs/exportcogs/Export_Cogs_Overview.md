# Export Cogs Subsystem Overview

The `/cogs/exportcogs` directory contains modules responsible for compiling match records and exporting game results to external cloud services, specifically Google Sheets for global community tracking.

## 📄 File Index

| File | Slash Command / Export | Description | Key Integrations |
| :--- | :--- | :--- | :--- |
| `exportstats.py` | `/exportstats` | Admin command to trigger immediate export of finished games to Google Sheets (`Games`, `Players`, `Votes`, `Analytics`, `Rules Setup`). | Calls `compiler.py` and `sheets_client.py`. |
| `compiler.py` | Data Processing Engine | Reads raw game JSON files from `/stats` and compiles player summaries, win rates, faction records, and setup rules configurations. | Reads [[Stats_Storage_Overview|/stats]]. |
| `sheets_client.py` | Google Sheets API Client | Authenticates via service account credentials (`data/ic-mafia-bot-*.json`), logs rules setup from `/mafiastart` (`Rules Setup` tab), and syncs rows to the master spreadsheet. | Uses `gspread` / Google Drive API. |

---

## 📊 Google Sheets Worksheets

| Worksheet | Generated By | Description |
| :--- | :--- | :--- |
| `Rules Setup` | `/mafiastart` & `/exportstats` | Tracks initial game configuration parameters across 18 columns (Game ID, scheduled time, admin, phase hours, role requirements, investigatability, GF/SK night kill immunity, Battle Royale day skip, story theme). |
| `Games` | Post-game export | Records completed game metadata (winner, end date, total days). |
| `Players` | Post-game export | Records player roles, factions, survival status, and causes of death. |
| `Votes` | Post-game export | Historical lynch voting history across all phases. |
| `Analytics` | Post-game export | Career player skill scores (Persuasion, Elusiveness, Understanding) and win/loss rates. |
